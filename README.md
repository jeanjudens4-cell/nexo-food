
# 🍽️ NEXO FOOD

### Descubra o prazer de cozinhar.

O NEXO FOOD é um site de receitas desenvolvido em grupo como projeto acadêmico. A plataforma permite explorar receitas, pesquisar pratos, consultar ingredientes e modos de preparo e salvar receitas favoritas.

## ✨ Funcionalidades

- 🏠 Página inicial moderna e responsiva.
- 🔎 Pesquisa de receitas por nome, categoria e descrição.
- 🍳 Listagem de receitas.
- 🥗 Filtros por categoria.
- 📖 Página com ingredientes e modo de preparo.
- ❤️ Sistema de favoritos usando localStorage.
- 📱 Layout adaptado para computadores, tablets e celulares.

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Git e GitHub
- Visual Studio Code
- Live Server

## 🚀 Como executar

1. Instale o Visual Studio Code.
2. Baixe ou clone o repositório.
3. Abra a pasta `nexo-food` no VS Code.
4. Instale a extensão Live Server.
5. Abra `index.html`.
6. Clique com o botão direito e selecione **Open with Live Server**.

Não é necessário instalar Node.js, pois o projeto utiliza HTML, CSS e JavaScript sem frameworks.

## ❤️ Favoritos

As receitas favoritas são armazenadas no navegador por meio do `localStorage`. Os dados ficam no navegador utilizado e não são sincronizados automaticamente entre dispositivos.
