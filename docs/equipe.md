
# Equipe — NEXO FOOD

## Objetivo

Desenvolver colaborativamente um site moderno de receitas utilizando HTML, CSS e JavaScript.

## Divisão de responsabilidades

### Integrante 1 — Front-end
- Desenvolver a página inicial.
- Implementar o layout dos cartões de receitas.
- Garantir a responsividade.
- Integrar os arquivos HTML e CSS.

### Integrante 2 — Receitas e JavaScript
- Organizar os dados das receitas.
- Implementar a pesquisa e os filtros.
- Desenvolver a página de detalhes.
- Testar os eventos e a manipulação do DOM.

### Integrante 3 — Favoritos e testes
- Implementar o sistema de favoritos.
- Testar a persistência com localStorage.
- Verificar os links entre páginas.
- Registrar e corrigir erros encontrados.

### Integrante 4 — Documentação e GitHub
- Manter o README atualizado.
- Organizar o repositório.
- Acompanhar commits e pull requests.
- Preparar a documentação da apresentação.

## Observação

Os integrantes podem acumular responsabilidades conforme o tamanho da equipe. Todos devem revisar e testar o projeto antes da entrega.
