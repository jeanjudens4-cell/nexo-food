
# Requisitos do NEXO FOOD

## Requisitos funcionais

- RF01: O sistema deve apresentar uma página inicial.
- RF02: O usuário deve conseguir visualizar as receitas.
- RF03: O usuário deve pesquisar receitas por texto.
- RF04: O usuário deve filtrar receitas por categoria.
- RF05: O sistema deve apresentar ingredientes e modo de preparo.
- RF06: O usuário deve adicionar e remover receitas dos favoritos.
- RF07: O sistema deve manter os favoritos no navegador.

## Requisitos não funcionais

- RNF01: O site deve ser responsivo.
- RNF02: O código deve ser organizado em arquivos separados.
- RNF03: A interface deve ser simples e intuitiva.
- RNF04: O site deve funcionar em navegadores modernos.
- RNF05: O projeto deve ser versionado com Git e GitHub.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Git e GitHub
